# CodeAlpha Task 3 – Data Visualization

## Project Overview
This project is part of my Data Analytics Internship at CodeAlpha. The main objective is to analyze book data and represent the information using different charts and visualizations.

## Dataset
The dataset contains book information collected from the Books to Scrape website using Python web scraping.

**Dataset details:**
- Book Name
- Price
- Availability

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created

### 1. Top 10 Most Expensive Books
A horizontal bar chart used to identify and compare the 10 most expensive books.

### 2. Distribution of Book Prices
A histogram used to understand the distribution of book prices.

### 3. Book Availability Analysis
A bar chart used to display the availability status of books.

## Key Insights
- Analyzed the prices of collected books.
- Identified the highest-priced and lowest-priced books.
- Calculated the average book price.
- Observed the availability status of books.

## Project Files
- `books_data.csv` – Dataset
- `CodeAlpha_Task3_Data_Visualization.ipynb` – Google Colab notebook
- `top_10_books.png` – Bar chart
- `price_distribution.png` – Histogram
- `book_availability.png` – Availability chart

## Conclusion
This project helped me understand data analysis and visualization using Python. I learned how to create charts, analyze datasets, and extract meaningful insights from data.
